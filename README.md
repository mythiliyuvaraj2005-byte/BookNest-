## 📖 About

**BookNest** is an online book ordering website developed using **HTML5 and CSS3**.

Users can browse books, view book details, add books to the cart, proceed to checkout, and receive an order confirmation.

---

## ✨ Features

- 🏠 Home Page
- 📚 Book Details
- 🛒 Shopping Cart
- 💳 Checkout Page
- ✅ Order Confirmation
- 🎨 User-Friendly Interface
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
